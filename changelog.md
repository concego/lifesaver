# Histórico de Versões - Lifesaver 🛟

## [1.2.0] - 2026-02-24

### ✨ Adicionado

* **Módulo de Estatísticas Literárias**: Contagem em tempo real de caracteres, palavras, linhas e cálculo automático de laudas (1400 caracteres por página).
* **Assistente de Inserção de Links**: Atalho `Ctrl + K` que abre uma caixa de diálogo para inserção direta de URLs no formato Markdown.
* **Assistente de Inserção de Imagens**: Atalho `Ctrl + G` focado em acessibilidade, solicitando o caminho do arquivo e o texto alternativo (Alt Text).
* **Exportação para PDF**: Integração com a função de impressão do sistema para gerar documentos prontos para submissão via `Ctrl + P`.
* **Menu de Ajuda Nativo**: Implementação de um manual rápido acessível via tecla `F1`.

### 🛠️ Melhorias e Correções

* **Otimização de Foco**: O cursor agora retorna automaticamente para o editor após o uso de assistentes de inserção, garantindo fluidez no uso com NVDA.
* **Correção de Acessibilidade**: Removida a redundância de leitura no painel de preview para evitar que o leitor de tela repita o conteúdo a cada tecla digitada.
* **Estabilidade de Interface**: Reorganização dos menus "Arquivo", "Inserir" e "Ferramentas" para uma navegação mais intuitiva via teclado.

## [1.0.0] - 2026-02-14

* **Lançamento Inicial**: Edição básica de texto, suporte inicial a Markdown e salvamento em formato `.txt`.
